What's real here

  • Temp mail is real: addresses are created live on Guerrilla Mail, Maildrop or SpamOK, the free services that still allow browser access (checked Oct 5, 2026). Emails you get here are real.

  • Bizzy Bot needs your own free API key (Gemini, Groq or OpenRouter). Keys are stored only in this browser's localStorage and sent only to the provider you choose.
